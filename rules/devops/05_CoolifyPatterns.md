# Coolify Deployment Patterns (DevOps)

> Coolify เป็น self-hosted alternative สำหรับ Vercel/Netlify — จัดการ server, deploy, SSL อัตโนมัติ

## 1. Overview

Coolify จัดการ:
- Docker-based deployments
- Automatic SSL (Let's Encrypt)
- Reverse proxy (Traefik built-in)
- Environment variables
- Database provisioning (MySQL, PostgreSQL, Redis, MongoDB)
- Webhook-based auto deploy from Git

## 2. Project Structure for Coolify

```
project/
├── Dockerfile                  # Coolify ใช้ build จากนี้
├── docker-compose.yml          # ถ้ามี multi-service
├── .env.example                # Template สำหรับ Coolify env vars
├── coolify.json                # (optional) Coolify config
└── ...
```

## 3. Deployment Types

### A. Dockerfile-based (Single Service)

```dockerfile
# Coolify จะ detect Dockerfile อัตโนมัติ
FROM node:22-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --production
COPY . .
EXPOSE 3000
CMD ["node", "dist/app.js"]
```

### B. Docker Compose-based (Multi-Service)

```yaml
# docker-compose.coolify.yml
services:
  api:
    build: ./backend
    environment:
      - DATABASE_URL=${DATABASE_URL}
      - REDIS_URL=${REDIS_URL}
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:3000/health"]
      interval: 10s
      timeout: 5s
      retries: 3

  web:
    build: ./frontend
    environment:
      - VITE_API_BASE_URL=${API_URL}
```

### C. Static Site (Frontend only)

```
# Coolify settings:
# - Build Command: npm run build
# - Output Directory: dist
# - Node Version: 22
```

## 4. Environment Variables

### In Coolify Dashboard

```
DATABASE_URL=mysql://user:pass@host:3306/db
REDIS_URL=redis://host:6379
JWT_SECRET=your-secret-key
NODE_ENV=production
```

### Rules

| Rule | Reason |
|---|---|
| Use Coolify dashboard for secrets | Encrypted at rest |
| `.env.example` in repo | Template only, no real values |
| Never commit `.env` | Gitignore |

## 5. Domain & SSL

Coolify จัดการอัตโนมัติ:
1. เพิ่ม domain ใน Coolify dashboard
2. Point DNS A record → server IP
3. Coolify auto-generates Let's Encrypt SSL
4. Auto-renewal

## 6. Database Provisioning

Coolify สามารถ provision:
- MySQL 8.0
- PostgreSQL 16
- Redis 7
- MongoDB 7

```
# Connection strings (auto-generated by Coolify)
DATABASE_URL=mysql://coolify:password@mysql:3306/app
REDIS_URL=redis://redis:6379
```

## 7. Auto Deploy

```
Git Push → Webhook → Coolify → Build → Deploy → Health Check
```

- Configure in Coolify dashboard: Settings → Git
- Supports GitHub, GitLab, Bitbucket webhooks
- Branch-based: select which branch triggers deploy

## 9. Limitations vs K8s

| Feature | Coolify | K8s |
|---|---|---|
| Complexity | Low | High |
| Scaling | Single server | Multi-node |
| Cost | Low | Medium-High |
| Custom middleware | Limited | Full Traefik CRD |
| Multi-environment | Manual setup | Native namespace |
| Best for | Small-medium projects | Enterprise/large scale |
